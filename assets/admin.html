Hide your own visits: on each browser/device where you load the portfolio, open DevTools console once and run localStorage.setItem("fw_is_me", "1") — events from that browser will be tagged is_self: true and hidden here unless you tick include my events. Undo with localStorage.removeItem("fw_is_me").

About locations: IP geolocation uses free databases that tag CGNAT exit IPs to the ISP's POP city, not where the user actually is. On Indian mobile networks (Jio/Airtel) expect city-level inaccuracy. Country is usually right.

About traffic sources: the tracker auto-classifies document.referrer into direct / search / social / ai / referral. To attribute specific posts or campaigns, share tagged links such as https://kushagrarathore.in/?utm_source=linkedin&utm_medium=social&utm_campaign=launch-2026. UTM params override the auto-classifier and appear in the Campaigns panel. First-touch acquisition is remembered per browser in localStorage["fw_first_touch"].
